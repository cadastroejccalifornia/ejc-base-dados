Circular icon button for floating toolbar actions and the nav rail. Pass a single icon glyph as children.

```jsx
<IconButton label="Buscar"><Icon name="search" /></IconButton>
<IconButton variant="dark" label="Adicionar"><Icon name="plus" /></IconButton>
```

Variants: default (white) · dark (brown) · soft (inset). Sizes: sm · md · lg.
