Pill action button for the EJC app; use `primary` (brown) for the main action on a screen, `secondary` for neutral actions, `ghost` for tertiary.

```jsx
<Button variant="primary" size="md">Salvar avaliação</Button>
<Button variant="secondary" iconLeft={<Icon name="plus" />}>Novo membro</Button>
```

Variants: primary · secondary · ghost · danger · yellow. Sizes: sm · md · lg. Use `block` for full-width, `iconLeft`/`iconRight` for Lucide glyphs.
